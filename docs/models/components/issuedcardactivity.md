# IssuedCardActivity

An issued card activity record. Each record represents the use of an issued card.

Exactly one of `authorizationID` or `cardTransactionID` is present:
- Activity that has an authorization request includes `authorizationID`. `cardTransactionID` is omitted.
- Activity that does not have a corresponding authorization request includes `cardTransactionID` and omits `authorizationID` and
 `authorizedAmount`.
