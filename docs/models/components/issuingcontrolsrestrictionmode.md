# IssuingControlsRestrictionMode

Whether the listed items are the only ones allowed (`allow`) or the ones to block (`block`).

## Example Usage

```ruby
require "moov_ruby"

value = IssuingControlsRestrictionMode::ALLOW
```


## Values

| Name    | Value   |
| ------- | ------- |
| `ALLOW` | allow   |
| `BLOCK` | block   |
