# OAuth2ClientType

The type of client requesting an OAuth2 token. Short codes are accepted as aliases for the corresponding client types.

## Example Usage

```ruby
require "moov_ruby"

value = OAuth2ClientType::WEB
```


## Values

| Name      | Value     |
| --------- | --------- |
| `WEB`     | web       |
| `DEVICE`  | device    |
| `SERVICE` | service   |
| `W`       | w         |
| `D`       | d         |
| `S`       | s         |
